# Jazykové mutace

Cíl: **CZ a EN plnohodnotně**, další jazyk se přidá jedním souborem bez zásahu
do kódu. Výchozí jazyk instalace je konfigurovatelný, uživatel si jej může
přepnout v UI.

---

## 1. Princip

Nikde v kódu ani v šablonách nesmí být text určený uživateli. Všude se používá
**klíč**, který se překládá až při zobrazení.

```javascript
// špatně
el.textContent = "Ohřev TUV zvýšen na 50 °C";

// správně
el.textContent = t("controller.dhw.raised", { temp: 50 });
```

To platí i pro **backend**: rozhodnutí controlleru se ukládá jako klíč + parametry,
nikoli jako hotová česká věta. Jinak by se historie po přepnutí na EN nedala číst.

```json
{"timestamp":"2026-08-19T13:02:11+02:00","rule":"dhw_pv_surplus","action":"set_dhw",
 "value":50,"reason_key":"reason.pv_surplus_high_soc",
 "reason_params":{"pv_kw":3.8,"soc":96,"price_czk":1.42}}
```

Log pro techniky (`logs/*.log`) zůstává anglicky a nepřekládá se – je to
diagnostika, ne uživatelské rozhraní.

## 2. Struktura katalogů

```text
dev/hec/locales/
├── cs.json      # referenční jazyk – zdroj pravdy pro sadu klíčů
├── en.json
└── <lang>.json  # další jazyky
```

Klíče jsou hierarchické a pojmenované podle **významu**, ne podle textu:

```json
{
  "nav": { "overview": "Přehled", "history": "Historie",
           "prediction": "Predikce", "settings": "Nastavení" },
  "overview": { "pv": "Výroba FVE", "house": "Spotřeba domu",
                "battery_soc": "Nabití baterie", "grid_import": "Odběr ze sítě",
                "grid_export": "Dodávka do sítě", "heatpump": "Tepelné čerpadlo" },
  "reason": {
    "pv_surplus_high_soc": "Přebytek FVE {pv_kw} kW, baterie {soc} %, nízká cena {price_czk} Kč/kWh",
    "price_high_use_inertia": "Vysoká cena {price_czk} Kč/kWh, využívá se setrvačnost podlahy"
  },
  "status": { "safe_mode": "Bezpečný režim", "stale_data": "Data starší než {age}" }
}
```

`en.json` má **identickou sadu klíčů**:

```json
{
  "nav": { "overview": "Overview", "history": "History",
           "prediction": "Forecast", "settings": "Settings" },
  "reason": {
    "pv_surplus_high_soc": "PV surplus {pv_kw} kW, battery {soc} %, low price {price_czk} CZK/kWh"
  }
}
```

## 3. Pravidla

1. **Klíč se nikdy nemění**, mění se jen jeho překlad. Změna významu = nový klíč.
2. `cs.json` je referenční. Test v CI porovná sadu klíčů všech jazyků proti němu
   a **selže** při chybějícím i přebývajícím klíči.
3. Chybějící překlad → fallback na `en`, pak na klíč samotný (nikdy prázdný text).
4. Parametry se předávají jako pojmenované `{placeholdery}`, nikdy skládáním
   vět z fragmentů – slovosled se mezi jazyky liší.
5. Množné číslo přes explicitní tvary (`one` / `few` / `many` / `other`) – čeština
   má tři tvary („1 hodina, 2 hodiny, 5 hodin“), angličtina dva.
6. Jednotky a formáty jsou součástí lokalizace, ne textu:
   * číslo: `7,2` (cs) vs. `7.2` (en) – přes `Intl.NumberFormat`,
   * datum: `19.08.2026` vs. `Aug 19, 2026` – přes `Intl.DateTimeFormat`,
   * měna: Kč / EUR podle konfigurace, ne podle jazyka,
   * teplota vždy °C; výkon kW; energie kWh (imperiální jednotky se neřeší).
7. Texty v `data-*` atributech, `aria-label`, `title` a v PWA manifestu se
   překládají také.
8. Délka textu: EN je typicky o 15–20 % kratší než CZ, DE o 30 % delší.
   Rozvržení se nesmí rozbít – žádné pevné šířky tlačítek a popisků.

---

## 4. Načítání

* Backend: `GET /api/i18n/{lang}` vrací celý katalog; frontend jej cachuje
  v `localStorage` s verzí buildu.
* Volba jazyka: uložená volba uživatele → `Accept-Language` → výchozí jazyk
  z konfigurace instalace → `en`.
* Přepnutí jazyka **nevyžaduje restart** ani nové načtení stránky.
* Katalogy jsou součástí offline cache service workeru – PWA musí fungovat
  bez připojení.

---

## 5. Přidání jazyka

1. Zkopírovat `cs.json` do `<lang>.json` a přeložit hodnoty.
2. Doplnit jazyk do seznamu v konfiguraci (`ui.languages`).
3. Spustit `pytest tests/test_i18n.py` – ověří úplnost sady klíčů.
4. Zkontrolovat zalomení v UI na mobilní šířce (nejdelší popisky v navigaci
   a v nastavení).

Žádný zásah do kódu není potřeba – to je akceptační kritérium této části.
